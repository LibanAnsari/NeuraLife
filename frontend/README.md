# NeuraLife Frontend

React 18 single-page application for the NeuraLife mental wellness platform.

## Quick Start

```bash
npm install
npm run dev
```

## Scripts

| Script | Description |
|--------|-------------|
| `npm run dev` | Start Vite dev server with HMR |
| `npm run build` | Production build |
| `npm run preview` | Preview production build |

## Components

| Component | Description |
|-----------|-------------|
| `Dashboard` | Main user dashboard |
| `Login` | Authentication (login/register/OAuth) |
| `Chatbot` | AI mental health chatbot |
| `MoodTracker` | Daily mood logging |
| `Journal` | Personal journaling |
| `SleepTracker` | Sleep quality tracking |
| `Quiz` | Mental health assessments |
| `Resources` | Curated resource library |
| `TherapySessions` | Therapist browsing & booking |
| `TherapyChat` | Real-time therapy messaging |
| `Premium` | NeuraLife+ subscription |
| `BreathingExercises` | Guided breathing exercises |

## Tech

- **React 18** with Vite for fast development
- **Tailwind CSS** for utility-first styling
- **Axios** for API communication
- **React Router** for client-side routing
