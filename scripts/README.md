# NeuraLife Scripts

Utility scripts for development setup and running the application.

## Setup Scripts

| Script | Description |
|--------|-------------|
| `setup_everything.bat` | Full project setup (backend + frontend + test data) |
| `setup_users.bat` | Create test users and therapists |

## Start Scripts

| Script | Description |
|--------|-------------|
| `start_backend.bat` | Start the FastAPI backend server (port 8000) |
| `start_frontend.bat` | Start the React frontend dev server (port 5173) |

## Maintenance Scripts

| Script | Description |
|--------|-------------|
| `restore_test_data.bat` | Restore test data to the database |
| `check_mood_tracker.bat` | Verify mood tracker endpoint |
| `install_oauth_dependencies.bat` | Install OAuth-related Python packages |
